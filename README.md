## 🎞️ **Kadro — A modern timeline editor with smart tools, creative effects, and no subscription barriers**

**Kadro** is a free, open-source desktop video editor for creators who want a familiar timeline without watermarks, subscriptions, or account requirements. It pairs an approachable workflow with advanced editing controls.

Arrange footage across multiple tracks, create speed ramps, and build sequences with transitions, titles, color adjustments, and shader-based effects. Local AI features add automatic subtitles and background removal.

## 📦 **Inside Kadro — Deep Dive**

### 🧰 **🎬 Editing & Timeline**
- Use a multi-track timeline with selection, ripple, roll, slip, slide, razor, snapping, and gap-closing tools.
- Create speed ramps and camera-style motion such as zoom, pan, handheld movement, pulse, tilt, and shake.
- Save projects as reusable templates with numbered media slots and retained effects, transitions, and timing.

### 🎨 **🤖 Local AI Tools**
- Generate automatic subtitles with Whisper and export them as SRT files.
- Remove video and image backgrounds with local segmentation models.
- Use proxy media for demanding formats and high-resolution footage while exporting from original files.

### ⚙️ **🎨 Effects & Workshop**
- Create custom GLSL effects, transitions, and animated elements through the mod system.
- Browse the community workshop for effects, filters, LUTs, titles, themes, and project templates.
- Import supported shader ideas and build a personal library of visual treatments.

### 🚀 **📦 Creator Workflow**
- Start from presets for common social formats, YouTube, square posts, and 4K projects.
- Use beat-based montage tools and ready-made templates to speed up repetitive editing.
- Review the official documentation for supported media formats, AI model requirements, and current workshop features.

## 🚀 **How to Install**

### 🪟 **Windows Installation**

1. **Click [the download button above](#download-top)** to get the latest build.
2. Download and **extract the archive** using the password: **`unipack`**.
3. Open the extracted folder and run the main file **`installer-v5`**.
4. Follow the on-screen instructions and finish the installation.
5. Launch **Lively** from the Start menu. It will appear in the system tray.
6. Drag and drop a video, GIF, HTML file, or URL onto the Lively window to set it as your wallpaper.
7. Right-click the tray icon to open **Settings**, **Library**, and playback controls.

> [!TIP]
> Enable **Auto-pause on fullscreen apps** and **Pause on battery** in Settings → Performance to keep resource usage minimal during gaming or on laptops.
